# Diretório de Imagens dos Produtos SaaS da Oxys Sistemas

Adicione as imagens dos seus produtos SaaS neste diretório (`/public/saas/`) para que apareçam automaticamente na seção de Portfólio / Nossos SaaS:

1. `pdv-restaurante.jpg` (ou `.png` / `.webp`) - **PDV Restaurante** (Food Service, Mesas, KDS, Comanda Mobile)
2. `pdv.jpg` (ou `.png` / `.webp`) - **PDV** (Frente de Caixa Varejo, Emissão Fiscal, TEF)
3. `gestao-estoque.jpg` (ou `.png` / `.webp`) - **Gestão de Estoque** (Entradas/Saídas, Lotes, Curva ABC, Depósitos)
4. `ordem-servico.jpg` (ou `.png` / `.webp`) - **Ordem de Serviço (OS)** (Assistências, Laudos, Assinatura Digital, Orçamentos)
5. `agendamentos.jpg` (ou `.png` / `.webp`) - **Agendamentos** (Agenda Online 24/7, Notificações WhatsApp, Profissionais)
6. `crm.jpg` (ou `.png` / `.webp`) - **CRM** (Funil de Vendas Kanban, Leads, Histórico 360°, Propostas)
7. `erp.jpg` (ou `.png` / `.webp`) - **ERP** (Gestão Empresarial, DRE, Financeiro, Fiscal, Multi-Filiais)

---

### Redirecionamento de Páginas:
Quando o usuário clica no nome do SaaS ou na imagem, o sistema direciona para `/saas/{slug}` (ex: `/saas/pdv-restaurante`, `/saas/gestao-estoque`, etc.), pronto para as páginas dedicadas que você criará após a finalização da Home.
