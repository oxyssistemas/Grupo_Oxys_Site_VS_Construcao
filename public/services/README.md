# Diretório de Fotos de Serviços da Oxys Sistemas

Adicione suas imagens/fotos neste diretório com os seguintes nomes de arquivos para que apareçam automaticamente nos cards de serviços:

1. `custom-software.jpg` (ou `.png` / `.webp`) - Para "Sistemas Web & Plataformas Sob Medida"
2. `mobile-apps.jpg` (ou `.png` / `.webp`) - Para "Aplicativos Mobile (iOS & Android)"
3. `apis-microservices.jpg` (ou `.png` / `.webp`) - Para "APIs Escaláveis & Microsserviços"
4. `integrations-gateways.jpg` (ou `.png` / `.webp`) - Para "Integrações de Sistemas & Pagamentos"
5. `cloud-devops.jpg` (ou `.png` / `.webp`) - Para "Cloud Architecture & DevOps"
6. `legacy-modernization.jpg` (ou `.png` / `.webp`) - Para "Modernização de Sistemas Legados"

Se desejar alterar os caminhos ou formatos, basta editar o arquivo `src/data/mockData.ts` no array `SERVICES_LIST`.
